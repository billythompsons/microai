# Contributing to MicroAI

MicroAI welcomes bug reports, documentation fixes, design feedback, and code.

1. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Search existing issues. Open a proposal before a large change.
3. Fork the repository and work in a focused branch.
4. Run `npm run check` and `npm run build`.
5. Explain the user problem, add tests, update docs, and attach before/after images for visual changes.

Local work needs Node.js 20+, Netlify CLI, and serverless PostgreSQL with pgvector. Copy `.env.example` to `.env`; never commit credentials or private source documents. Contributions are licensed under Apache-2.0.
